# CyberCheck

A static GitHub Pages starter site for a website cybersecurity checker.

## Run locally

Open `index.html` in a browser. The site uses plain HTML and CSS and has no build step or external dependencies.

## Publish with GitHub Pages

1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then save.
4. After the deployment finishes, visit `https://djkiaikat.github.io/`.

Changes pushed to the root of `main` will be published automatically. GitHub Pages may take a few minutes to publish the first time.

## Project status

This is the initial static site scaffold. It does not currently perform security checks; add and review any checking functionality before presenting results as security findings.
